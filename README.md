SloppyMusicReader is an AI generated web app to help musicians
practice reading musical notation.

https://neko-milkshake.github.io/SloppyMusicReader/

The app features practice on treble and bass clef, current note streak,
max note streak, average answer time and achievements for correct
answer streaks.

The user can answer with the UI buttons, with the keyboard matching
the notes (A, B, C, D and so on) and MIDI input with supported browsers.

The app takes into account missed notes, or the ones that took longer
to answer and shows them more often to help memorize them.

There's also light and dark themes. :) 

This is an app i made for myself because music reading always felt overwhelming,
I hope it is useful to you too!
